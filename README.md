# Bicycle, Meal & Mushroom Management System

## Open and run
1. Extract this ZIP file.
2. Open **BicycleMealManagement.sln** from the extracted main folder.
3. Use Visual Studio 2022 with the **.NET desktop development** workload and .NET 8 SDK.
4. Press **F5** to run.
